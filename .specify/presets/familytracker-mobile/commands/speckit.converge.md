## FamilyTracker evidence and documentation

Read the approved scope, interview if present, actual source diff, API references,
verification.md and tasks.md. Check UI states, vi/en, shared consumers, cancellation,
API mappings and scoped refactor. Do not claim device, visual, performance or XCTest
verification without running it. Record blocked/skipped checks with their reason.

For substantive features maintain study.md in Vietnamese using actual source links,
architecture/data flow/state/API/reuse/refactor/performance trade-offs/tests/debugging.
Keep tasks.md as the sole task checklist; progress.md contains phase, approval and
contract status, evidence references and remaining task IDs, not a duplicate checklist.
Convergence must not authorize new scope: append necessary gaps to tasks, and request
renewed approval for material behavior, architecture, API or refactor changes.

For UI scope follow .specify/design-workflow.md: review real screenshots, text scaling,
appearance, accessibility and safe areas. Report inaccessible authenticated states
without fabricating status/locations or marking visual QA complete.
