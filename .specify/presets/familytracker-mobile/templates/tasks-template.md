## FamilyTracker Task Rules

Giữ native `- [ ] TNNN [P?] [USn] Description with real file path` và story phases;
chỉ dùng [P] cho task độc lập. Mỗi task có tiêu chí kiểm chứng liên kết FR/story.
Không giữ nguyên các sample task/path không áp dụng.

Trong scope thực tế, bao phủ contract analysis → DTO/model/shared API → UseCase →
state/UI/Coordinator → relevant tests → approved refactor → verification → docs/study
→ converge. Với feature không dùng Backend, đánh dấu API N/A, không tạo task giả.
Interview/analysis phải xong trước approval; task implementation bị chặn khi chưa duyệt.
Ghi task ID bị blocked trong progress.md, không đánh dấu task hoàn tất vì đã liệt kê.
Cập nhật vi/en cùng nhau khi có UI. Dùng verification.md cho bằng chứng test và giới
hạn; study.md bằng tiếng Việt cho feature đáng kể. Không lặp checklist task trong
progress.md hoặc PROGRESS.md.
